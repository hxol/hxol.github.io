# 交换机 VLAN 转发逻辑：PVID、VID 及 Tag & Untag 处理机制

在网络配置中，VLAN（虚拟局域网）是最基础也是最核心的技术之一。但很多网络工程师在面对 Access、Trunk、Hybrid 以及 PVID、VID、Tag/Untag 时，经常会被绕晕。

这篇文章将带你拨开迷雾，从交换机的底层处理逻辑出发，彻底搞懂 VLAN 报文的转发机制。

## 核心概念：PVID 与 VID
在深入规则之前，必须先理清两个基本概念：
* **PVID (Port VLAN ID)**：端口的缺省（默认）VLAN ID。它决定了一个“不带标签 (Untagged)”的数据包进入该端口时，会被打上什么 VLAN 标签。
* **VID (VLAN ID)**：数据帧中 802.1Q 标签所标明的 VLAN ID，或者指端口配置中允许放行的 VLAN 列表。

**一个必须牢记的“法则”**：
**在交换机内部，为了快速高效地处理和区分不同 VLAN 的流量，所有的数据帧都是带 Tag 的。** 所谓的 Untag 报文，只存在于交换机的外部链路（如连接 PC）上。

---

## 核心处理机制：入方向与出方向

判断一个报文该如何处理，只需严格区分它是**进入交换机（入方向）**还是**离开交换机（出方向）**。

### 1. 报文入方向 (Ingress)
入方向的核心任务是：**决定该报文是否被允许进入端口，并为其分配内部 VLAN 标签。**

* **当收到 Untag 报文时**：
  毫无条件地允许进入，并立刻给它打上该端口 **PVID** 的 VLAN Tag。（与端口类型无关，所有端口处理方式相同）
* **当收到 Tag 报文时**，交换机需要根据端口类型进行判断：
  * **Access 端口**：严格检查。只有当报文的 Tag 与端口的 PVID 完全一致时才接收；否则直接丢弃。
  * **Trunk / Hybrid 端口**：查阅允许列表。如果报文的 Tag 在该端口允许放行的 VLAN 列表中，则接收并保持 Tag；否则丢弃。

### 2. 报文出方向 (Egress)
出方向的核心任务是：**交换机已经完成了内部转发，在把报文送出端口前，决定是否要剥离掉 Tag（脱标签）。**

* **Access 端口**：直接剥离掉 Tag，**不带标签 (Untag)** 转发。（因为对面通常是 PC 或服务器，不认识 VLAN 标签）。
* **Trunk 端口**：
  * 如果报文的 VLAN ID **等于** 端口的 PVID（即 Native VLAN），则剥离标签，**Untag** 转发。
  * 如果报文的 VLAN ID **不等于** 端口的 PVID，则保留标签，**带 Tag** 转发。
* **Hybrid 端口**：极其灵活，完全根据管理员的配置来决定。如果配置该 VLAN 在 `untagged` 列表中就剥离标签；如果在 `tagged` 列表中就保留标签。

## 厂商语境差异：Cisco vs H3C/华为

很多初学者觉得乱，是因为不同厂商（如 Cisco 与 H3C/华为）在概念表述上存在差异：

1. **“虚标签”与“实标签”**：
   在 Cisco 语境中，PVID 更多是一个**本地概念 (Local Concept)**。PC 的流量进入 Access 口，交换机只是在本地内存/转发表中为其分配了一个 VLAN 归属（我们可以理解为“虚标签”）。只有当数据包从 Trunk 口离开交换机，打上了真正的 802.1Q 报头时，才是“实标签”。
2. **Native VLAN**：
   Cisco 中常说的 Native VLAN，本质上就是 Trunk 链路上的 PVID。它的意义仅存在于 Trunk 链路上——两端交换机约定好，针对这个特定的 VLAN，大家都不打标签。
3. **严格的 Access 机制**：
   在 Cisco 设备上，Access 接口如果收到带有 Tag 的报文（即便 Tag 与 PVID 相同），通常也会直接丢弃，这点在实际抓包排错时需要特别注意。

## 通俗比喻：房子、房间与制服

如果你觉得上面的规则太枯燥，不妨用这个“大房子”的比喻来理解：

* **交换机** = 一个有很多房间的大房子。
* **Access 端口** = 房间门。
* **Trunk 端口** = 房子的大门（连接另一栋房子）。
* **数据包** = 进出的人。
* **VLAN Tag** = 印有特定颜色/编号的制服。

**场景模拟：**
1. **进入房间 (Access Ingress)**：一个人（Untag报文）从外面走进某个房间（Access口），房间管理员（交换机）规定，只要进了这个房间，内部活动就必须穿上该房间专属的红色制服（打上 PVID）。
2. **房子内部 (Switch Fabric)**：大家在房子里转悠时，都穿着各自的制服（内部全部带 Tag），这样管理员就能轻松区分谁属于哪个区域。
3. **离开房间 (Access Egress)**：这个人要离开房子回家了（流向PC）。因为外面的人不认这套制服，所以出门前必须脱下制服（剥离 Tag）。
4. **走出大门去另一栋房子 (Trunk Egress)**：当这个人要通过大门（Trunk口）去另一栋大房子时，为了让对面的管理员知道他属于哪个区，他**必须穿着制服过去（带 Tag 转发）**。
5. **Native VLAN (不穿制服的特权)**：两栋房子的管理员私下约定了一个特权区（Native VLAN / Trunk PVID）。如果是这个区的人过大门，**可以不穿制服（Untag）**，对方只要看到没穿制服的人，就默认他是特权区的。

## 总结速查表

| 端口类型 | 接收 Untag 报文 (入) | 接收 Tag 报文 (入) | 发送报文 (出) |
| :--- | :--- | :--- | :--- |
| **Access** | 打上 PVID 标签并接收 | Tag=PVID 则接收，否则丢弃 | 剥离标签 (Untag) 发送 |
| **Trunk** | 打上 PVID 标签并接收 | Tag在允许列表中则接收，否则丢弃 | VLAN=PVID 则剥离标签(Untag)<br>VLAN≠PVID 则保留标签(Tag) |
| **Hybrid**| 打上 PVID 标签并接收 | Tag在允许列表中则接收，否则丢弃 | 根据配置决定剥离(Untag)或保留(Tag) |
