# POS机业务与技术维护知识库

## 一、 基础概念与行业常识

### 直联POS与间联POS的区别
商户在申请机器时常会接触到“直联”与“间联”的概念，核心区别在于**商户与谁签署收单协议**以及**数据传输链路**：

*   **直联POS**：终端直接连接银联主机。当持卡人刷卡时，交易数据直接发送至发卡行，收单行不会在中途获取底层信息。与银联商务直接签约的机器多属此类。
*   **间联POS**：终端先连接收单机构（如某商业银行或第三方支付公司）的主机系统。发生跨行消费时，数据先到收单机构，再由其上送银联转接至发卡行。目前绝大多数商业银行与第三方机构发放的机器均属间联模式。

*行业背景补充：银行与银联在收单业务上存在一定的博弈。间联模式便于收单行掌握交易数据，而银行从风控角度往往认为直联机更容易脱离其监管，从而衍生违规交易。*

### MCC码（商户类别码）释义
持卡人消费成功后的签购单（小票）上会有一串商户编号，其中**第8至11位（共4位数）**即为MCC码。

*   **核心作用**：MCC码由收单机构为特约商户设置，标明商户的主营业务范围与行业归属。它是银联判断跨行交易结算手续费标准的主要依据，也是风控管理的重要数据基础。
*   **费率参考（注：以下为2015年旧版标准）**：民生类（如超市）约为0.38%，一般类（如百货）约为0.78%，餐娱类（如餐饮娱乐）约为1.25%。*(注：2016年“96费改”后，已统一为标准类、优惠类、减免类，不再按此细分行业费率)*。
*   **套码风险**：商户务必确保终端设置的MCC码与实际经营业务相符。若被银联或银行风控系统识别为“套码”（小票MCC与实际不符），面临的处罚包括但不限于撤机、冻结资金甚至封停账户。切勿因贪图低费率而因小失大。

### 小票商户编号规则解析
标准的商户编号由15位数字组成，拆解如下：

*   **机构代码（前3位）**：代表收单机构。
    *   *示例*：102工商银行、103农业银行、104中国银行、105建设银行、301交通银行、308招商银行、100邮储银行、001中国银联、302中信实业银行、303中国光大银行、304华夏银行、305中国民生银行、306广东发展银行、307深圳发展银行 、309兴业银行、310上海浦东发展银行等。
*   **地区码（第4至7位）**：行政区划代码，与身份证前四位一致，精确到地级市。
    *   *示例*：北京1100、上海2900、广东4400、江苏3200等。
*   **商户类型（第8至11位）**：即上述的MCC码。
*   **商户顺序号（后4位）**：由收单机构内部分配的流水号。

## 三、 终端日常交易操作流
*(注：默认主管密码一般为 `123456`，操作员 `01`，密码 `0000`)*

### 1. 签到 (Device Login)
日常无特殊提示无需频繁签到。如遇设备脱机或要求签到，请执行：
*   待机界面按“确认”键 -> 选择“管理” -> 选择“签到”
*   输入操作员号（默认 `01` 或 `02`） -> 输入操作员口令（默认 `1111` 或 `2222`）
*   等待系统连接金卡中心处理，提示“签到成功”即可。

### 2. 消费交易 (Purchase)
*   待机界面提示“请刷卡”时，直接刷卡/插卡/挥卡
*   核对屏幕显示的卡号 -> 按“确认”键
*   输入交易金额（注意小数点） -> 按“确认”键
*   交由持卡人输入密码（无密码直接按确认） -> 打印机出票。

### 3. 消费撤销 (Void)
用于结算前，因收银员操作失误需要取消当天的交易。
*   待机界面按“确认”键 -> 选择“撤销”
*   输入主管密码（如 `123456`） -> 输入小票上的**原交易凭证号**（流水号）
*   核对屏幕显示的原交易信息 -> 再次刷需撤销的银行卡
*   持卡人输入密码确认 -> 打印撤销单据，资金退回。

### 4. 退货 (Refund)
用于撤销**非当天**或**已结算**的交易（此功能通常需要提前向开户行提交书面申请方可开通）。
*   按“确认”键 -> 选择“撤销” -> 选择“退货”
*   输入主管密码 -> 刷原交易银行卡 -> 核对卡号
*   依次输入：原交易参考号 -> 原交易日期 -> 原交易金额
*   持卡人输密确认 -> 打印单据等待到账。

### 5. 日终结算 (Settlement)
汇总POS机记录的当日交易总额与总笔数，并清空本地流水。
*   按“确认”键 -> 选择“结算”
*   核对屏幕显示的交易笔数及金额 -> 确认并等待系统处理
*   打印结算对账单，系统流水自动清空。

## 四、 设备安装、巡检与程序下载

### 现场硬件排查与巡检
*   **通讯介质检查**：
    *   执行一次“签到”操作，测试与银联中心的连接是否通畅。
    *   检查电话是否欠费、网线/电话线接口是否插错（母机连LINE口，待装机连RS232或指定口）。
*   **硬件防混淆**：核对主机与外接密码键盘是否匹配，严禁不同机具接口混插。
*   **配置核对**：检查通讯方式（网络/电话/GPRS）与商户信息是否被私自篡改。
*   **异常处理方案**：
    *   遇到 `MAC校验码错误`：通常重新做一次**签到**即可解决。
    *   无法读取芯片卡（IC卡）：带回公司检修或更换机具。
    *   带独立密码键盘且使用一年以上的终端：建议撤机重新做系统安装。

### 新国都 K320 / K370 程序更新与设置
**通用前置准备**：登记机具号与机型、制作分配表（由内部统筹专员处理）、准备装有配置程序的U盘。

**K320 / K370 U盘下载流程**：
*   在电脑端修改U盘中 `sposparam.ini` 文件内的：商户号、终端号、商户名称。
*   弹出U盘并插入POS机。
*   **K320**：按住 `2` + `5` + `0` + 开机键，开机 -> 选择 `2` -> 输入密码 `888888` -> 选 `9` -> 选 `2` -> 下载完成后关机。重新开机按 `F2` + `1` -> 密码 `556677` -> 选 `3` -> 选 `2`，完成。
*   **K370**：按住 `F` + `1` + 开机键 -> 密码 `556677` -> 选 `3` -> 选 `2` -> 完成后重启机具。*(注：批量作业时，记得每次更换U盘内ini文件中的参数)。*

**K320 网线模式 (LAN) 配置流**：
*   输入操作员 `99` -> 密码 `88888888` -> 进入系统设置
*   选择通讯参数设置 -> 选择 `LAN`
*   修改网线 TPDU 为：`6005010000`
*   输入对应运营商的服务器IP及端口（参考上文参数字典） -> 持续按取消退回主界面即可。

**K320 电话线模式 (Modem) 配置流**：
*   同上进入系统设置 -> 通讯参数设置 -> 选择 `Modem`
*   外线号码按需填写或留空
*   修改电话线 TPDU 为：`6004500000`
*   将电话号码1、2、3均修改为：`8006536086` -> 持续按取消退回主界面。

### 百富 S58 与通用终端设置说明
*   **S58 程序下载**：插好电源侧边线 -> 开机按“菜单” -> 刷新 -> 编辑 -> 选择应用并下载 -> 选择参数并下载。
*   **通讯长短连接**：通常TCP长短连接保持默认即可。
*   **外置键盘设置匹配**：
    *   进入设备终端参数设置菜单（操作员99进系统）。
    *   若**带独立外置密码键盘**：非接读卡器接口选择 `3`。
    *   若**为一体机（内置键盘）**：非接读卡器接口选择 `4`。
*   **无线POS（GPRS机型）**：流量卡通常置于机身最左侧卡槽。务必在系统通讯方式中更改为 `GPRS`。

## 五、 常见报错代码字典（故障速查）

> *快速排障原则：大多数通讯或校验类报错，先尝试重新**签到**；若是卡片本身风险问题（黑卡、挂失卡），切勿强制多次刷卡。*

### 00 - 10 系列：基础故障
*   **00**：交易成功。
*   **01 / 02**：交易失败，请联系发卡行（通常需查发卡行状态或卡内余额）。
*   **03**：商户未登记（机器无权使用银联网络，需联系服务中心处理）。
*   **04 / 07**：没收卡（高风险卡片，有黑卡或伪卡嫌疑，应予以没收或拒刷）。
*   **05**：发卡不予承兑（发卡行拒绝交易）。
*   **06**：发卡行故障（稍等片刻重新刷卡）。
*   **09**：重做该交易（稍等重新刷卡）。

### 11 - 30 系列：卡片与接口问题
*   **12**：不支持的交易（可能是部分银行未签清算协议或不识别该刷卡器）。
*   **13**：交易金额超限（单笔限额，建议小额多笔或向银行申请临时额度）。
*   **14**：无效卡号（卡片未激活、已注销或长时间未交年费）。
*   **15**：此卡不能受理（未接入银联网络，不予清算）。
*   **19**：读取数据有误（磁条/芯片读取失败，请重刷）。
*   **22**：操作有误（POS状态与中心不符，请重新**签到**后重试）。
*   **23**：不可接受的交易费（资金存在风险或未签银联协议）。
*   **25**：发卡行未能找到有关记录。
*   **30**：检查卡磁条是否完好或反方向刷卡。

### 31 - 50 系列：风控与高风险卡
*   **31**：此发卡方未与中心开通业务。
*   **33 / 54**：过期卡（卡片有效期已过，结算功能暂时冻结）。
*   **34 / 35 / 36 / 37 / 41 / 43**：没收卡 / 作弊嫌疑 / 挂失卡 / 被窃卡（极高风险！极可能是盗刷或伪卡，应终止交易防范风险）。
*   **38 / 75**：密码错误次数超限（保护机制触发，通常需等24小时解冻或联系发卡行）。
*   **39**：未找到处理内容（交易失败，操作可能有误或批次不一致，需重新签到）。
*   **40 / 44**：发卡行不支持此类型，或刷卡操作有误。
*   **42**：发卡行找不到此账户（黑卡风险）。
*   **45 / 82**：**降级交易拒绝（关键提示）**！意味着该卡属于复合卡，不能使用刷磁条模式，**必须插入芯片（IC）交易**。

### 51 - 70 系列：资金与额度限制
*   **51**：余额不足（建议查询余额或小额刷卡）。
*   **55**：密码错误（注意最多试3次以免冻结）。
*   **57 / 62**：不允许持卡人进行的交易 / 受限制的卡（持卡人曾有套现等违规行为，已被银行风控系统监控）。
*   **58**：终端无效（重新**签到**，或联系代理商/收单行重新录入终端）。
*   **61**：金额太大，超出提款限额。
*   **65**：超出取款次数限制（银行系统风控控制）。
*   **66**：磁条不识别或已消磁。
*   **68**：交易超时（发卡行未在规定时间内应答，重新签到后重做）。

### 71 - 99 系列：系统级故障与通讯超时
*   **77 / 99 / A0**：需重做签到 / 批次号不一致 / 校验错 / MAC错（核心解决办法：执行**签到**操作以同步密钥）。
*   **79**：POS终端重传脱机数据不平（检查网络接口与连接）。
*   **90 / 91 / 92**：日期切换处理中 / 通讯故障（银行系统日终处理或网络波动，稍后再试）。
*   **93**：交易违法不能完成（触发反套现或恶意透支报警系统）。
*   **94 / 98**：银联收不到发卡行应答（交易超时，重新签到再试）。
*   **96**：发卡行或银联系统异常报警。
*   **97**：终端未登记（资料未通过审核或机具尚未绑定入网）。
