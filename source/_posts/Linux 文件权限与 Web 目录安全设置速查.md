# Linux 文件权限与 Web 目录安全设置速查

## 1. 查看权限
使用 `ls -l` 查看详细信息：
```bash
# 查看文件权限
ls -l filename

# 查看目录本身权限 (-d)
ls -ld directory
```

### 1.1 权限位解析
输出示例：`drwxr-xr-x`
- **第 1 位**：文件类型 (`d`: 目录, `-`: 文件, `l`: 链接)
- **第 2-4 位** (`rwx`)：**所有者 (User/Owner)** 的权限
- **第 5-7 位** (`r-x`)：**所属组 (Group)** 的权限
- **第 8-10 位** (`r-x`)：**其他人 (Others)** 的权限

### 1.2 权限含义对照表
| 符号 | 数字 | 含义 | 对文件 | 对目录 |
| :---: | :---: | :--- | :--- | :--- |
| **r** | 4 | Read (读) | 查看文件内容 | 列出目录内容 (`ls`) |
| **w** | 2 | Write (写) | 修改文件内容 | 创建/删除文件 (`touch`/`rm`) |
| **x** | 1 | Execute (执行) | 运行脚本/程序 | 进入目录 (`cd`) |
| **-** | 0 | 无权限 | 拒绝访问 | 拒绝访问 |

---

## 2. 修改权限 (chmod)
命令格式：`chmod [选项] 模式 文件/目录`
常用选项：`-R` (递归修改，包含子目录和文件)

### 2.1 数字设定法 (推荐)
权限值 = r(4) + w(2) + x(1)

| 常用组合 | 数字 | 含义 (User / Group / Others) | 场景 |
| :--- | :--- | :--- | :--- |
| **600** | `rw-------` | 只有所有者可读写 | SSH 密钥, 配置文件 |
| **644** | `rw-r--r--` | 所有者读写，其他人只读 | **标准网页文件** |
| **755** | `rwxr-xr-x` | 所有者全权，其他人读+执行 | **标准网站目录**, 脚本 |
| **700** | `rwx------` | 只有所有者全权 | 只有你能进的目录 |
| **777** | `rwxrwxrwx` | 所有人都有全部权限 | **极度危险，禁止使用** |

```bash
# 修改文件为 644 (标准安全权限)
chmod 644 file.txt

# 递归修改目录及其内容为 755
chmod -R 755 /var/www/html
```

### 2.2 文字设定法
格式：`[u/g/o/a] [+ / - / =] [r/w/x]`
- 对象：`u` (User), `g` (Group), `o` (Others), `a` (All)
- 动作：`+` (添加), `-` (删除), `=` (赋予)

```bash
# 给所有人添加执行权限
chmod a+x script.sh

# 禁止其他人写入
chmod o-w file.txt

# 只有所有者可读写 (等同 600)
chmod u=rw,go= file.txt
```

## 3. 修改归属 (chown)
命令格式：`chown [选项] 用户:组 文件/目录`

```bash
# 修改所有者为 nginx，组为 nginx
chown nginx:nginx file.txt

# 递归修改目录归属
chown -R www-data:www-data /var/www/html
```

## 4. Web 网站目录安全设置
**核心原则**：
1. **最小权限**：目录不要给写权限 (w)，文件不要给执行权限 (x)。
2. **读写分离**：Web 服务进程（如 Nginx/Apache）只应该对上传/缓存目录有写权限，对代码文件只有读权限。

### 4.1 推荐方案
假设：
- Web 运行用户：`www` (nginx/apache)
- 网站维护用户：`centos` (负责上传代码)
- 网站根目录：`/home/centos/web`

**步骤 1：设置归属**
将文件所有者设为维护用户，所属组设为 Web 运行用户。
```bash
# 所有者拥有管理权，Web 进程作为组用户只有读权限
chown -R centos:www /home/centos/web
```

**步骤 2：设置基础权限**
- **目录 (750)**：所有者(rwx)可管理，Web进程(r-x)可读取/进入，其他人无权限。
- **文件 (640)**：所有者(rw-)可修改，Web进程(r--)可读取，禁止修改代码，其他人无权限。

```bash
# 批量设置目录权限
find /home/centos/web -type d -exec chmod 750 {} \;

# 批量设置文件权限
find /home/centos/web -type f -exec chmod 640 {} \;
```

**步骤 3：开放特殊目录写入权**
对于需要写入的目录（如 `uploads`, `cache`, `logs`），单独赋予 Web 进程写权限。
```bash
# 赋予组用户 (www) 写权限，变为 770
find /home/centos/web/uploads -type d -exec chmod 770 {} \;
# 或者
chmod -R 770 /home/centos/web/uploads
```

### 4.2 为什么这样设置？
- **防篡改**：Web 进程被入侵后，黑客只有读权限，无法修改 PHP/HTML 代码挂马。
- **防执行**：上传目录只有写权限，没有执行权限，黑客上传了木马脚本也无法运行。
