# Linux `printf` 命令指南

`printf` 是一个功能强大的文本格式化工具，其名称源自 C 语言的 `printf()` 函数。与 `echo` 相比，`printf` 不会自动添加换行符，但提供了极其丰富的格式控制能力，特别适合生成报表、处理数据对齐和复杂的字符串输出。

## 1. 基础语法

```bash
printf "格式字符串" [参数...]
```

*   **格式字符串**：包含普通文本、转义字符（如 `\n`）和格式替换符（如 `%s`）。
*   **参数**：被格式化的文本或数字。如果不提供参数，`%s` 用空字符串代替，`%d` 用 0 代替。

## 2. 快速上手

### 2.1 基础输出与换行
`printf` 默认不换行，需手动添加 `\n`。

```bash
# echo 会自动换行
echo "Hello Linux"

# printf 需要显式添加 \n
printf "Hello Linux\n"
```

### 2.2 自动循环格式化（核心特性）
这是 `printf` 最强大的特性之一。如果参数多于格式说明符，`printf` 会**循环重用**格式字符串，直到所有参数处理完毕。

**场景**：将一行中的多个单词分行输出。

```bash
# 命令
printf "%s\n" abc def ghi

# 输出
abc
def
ghi
```

### 2.3 简单表格处理
利用循环特性，可以轻松处理结构化数据。

```bash
# 命令：每两个参数为一组，分别对应 %s 和 %s
printf "%s %s\n" 1 a 2 b 3 c

# 输出
1 a
2 b
3 c
```

---

## 3. 常用格式替换符

替换符用于指定参数的输出格式，以 `%` 开头。

| 替换符 | 描述 | 示例 |
| :--- | :--- | :--- |
| **`%s`** | **字符串**（最常用） | `printf "%s" "test"` |
| **`%d`** 或 **`%i`** | 有符号十进制整数 | `printf "%d" 100` |
| **`%f`** | 浮点数（默认保留6位小数） | `printf "%f" 10.5` |
| `%b` | 解析参数中的转义字符 | `printf "%b" "A\nB"` (会换行) |
| `%c` | ASCII 字符（只取参数第一个字符） | `printf "%c" "Apple"` -> `A` |
| `%o` | 无符号八进制数 | `printf "%o" 10` -> `12` |
| `%x` / `%X` | 无符号十六进制数 (a-f / A-F) | `printf "%X" 15` -> `F` |
| `%%` | 输出 `%` 字符本身 | `printf "%d%%" 80` -> `80%` |

> **注意**：使用 `%s` 时，如果参数包含空格，建议用双引号将参数括起来。

## 4. 格式修饰符（对齐、宽度与精度）

通过在 `%` 和 `格式字符` 之间添加修饰符，可以控制文本的对齐方式、宽度和精度，这对于制作表格非常有用。

语法结构：`%[标志][宽度][.精度]类型`

### 4.1 宽度与对齐

*   **`%N`**：指定最小宽度为 N。内容不足 N 时，默认**右对齐**，左侧补空格。
*   **`%-N`**：指定最小宽度为 N。内容不足 N 时，**左对齐**，右侧补空格。

**示例：制作一个对齐的表格**

```bash
# 表头
printf "%-10s %-8s %-4s\n" 姓名 性别 年龄
# 数据
printf "%-10s %-8s %-4d\n" 露露 女 18
printf "%-10s %-8s %-4d\n" 史莱克 男 25

# 输出结果：
# 姓名     性别   年龄
# 露露     女     18  
# 史莱克   男     25  
```
*(注：`%-10s` 表示占用10个字符宽度并左对齐)*

### 4.2 精度控制

*   **对于浮点数 (`%f`)**：`.N` 表示小数点后保留 N 位。
*   **对于整数 (`%d`)**：`.N` 表示数字的总长度，不足时高位**补零**。
*   **对于字符串 (`%s`)**：`.N` 表示截取字符串的前 N 个字符。

**示例：**

```bash
# 1. 浮点数精度
printf "Val: %.2f\n" 1.2      # 输出: Val: 1.20
printf "Val: %.2f\n" 1.23456  # 输出: Val: 1.23

# 2. 整数补零 (常用于生成编号)
printf "%.5d\n" 12            # 输出: 00012

# 3. 截取字符串
printf "%.3s\n" "abcdefg"     # 输出: abc
```

### 4.3 符号显示 (`+`)

*   **`+`**：显示数字的正负号（默认正数不显示符号）。

```bash
printf "%d\n"  10   # 输出: 10
printf "%+d\n" 10   # 输出: +10
printf "%+d\n" -5   # 输出: -5
```

## 5. 转义字符序列

`printf` 支持常见的转义字符，使用时通常配合双引号。

| 转义符 | 描述 |
| :--- | :--- |
| `\n` | 换行 (New Line) |
| `\t` | 水平制表符 (Tab) |
| `\v` | 垂直制表符 |
| `\b` | 退格 (Backspace) |
| `\r` | 回车 (Carriage Return) |
| `\f` | 换页 |
| `\\` | 反斜杠本身 |
| `\a` | 警告音 (Bell) |
| `\0nnn` | 八进制值表示的字符 |

**示例：给输出添加括号**

```bash
printf "( %s ) \n" 1 2 3
# 输出：
# ( 1 ) 
# ( 2 ) 
# ( 3 ) 
```

## 6. 综合案例总结

假设我们需要打印一份整齐的员工体温记录表。

**原始数据：**
姓名：烈火兽，体温：180，性别：男
姓名：冰河兽，体温：-20，性别：女

**目标：**
1.  姓名左对齐，宽10字符。
2.  性别左对齐，宽5字符。
3.  体温右对齐，强制显示正负号，保留1位小数，宽8字符。

**命令：**

```bash
# 打印表头
printf "%-10s %-5s %8s\n" "姓名" "性别" "体温"

# 打印数据
printf "%-10s %-5s %+8.1f\n" "烈火兽" "男" 180
printf "%-10s %-5s %+8.1f\n" "冰河兽" "女" -20

# 终端输出结果：
# 姓名       性别         体温
# 烈火兽     男         +180.0
# 冰河兽     女          -20.0
```

通过这个例子，你可以看到 `printf` 如何利用 `%-10s` (左对齐)、`%+8.1f` (带符号、宽度、精度) 来完美控制输出格式。
