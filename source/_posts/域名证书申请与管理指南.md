# 域名证书申请与管理指南

[acme.sh 官方 GitHub 仓库](https://github.com/acmesh-official/acme.sh)


## 安装 acme.sh

安装前请确保系统已安装必要的依赖。为了确保环境干净，建议使用 `root` 权限或具有 `sudo` 权限的用户进行操作。

*   **安装依赖**
    ```bash
    sudo apt update && sudo apt install socat curl -y
    ```

*   **一键安装脚本** (以下三种方式任选其一即可)：
    *   *方式 A (Curl)*:
        ```bash
        curl https://get.acme.sh | sh -s email=admin@example.com
        ```
    *   *方式 B (Wget)*:
        ```bash
        wget -O -  https://raw.githubusercontent.com/acmesh-official/acme.sh/master/acme.sh | sh -s -- --install-online -m admin@example.com
        ```
    *   *方式 C (Git - 适合网络环境受限的情况)*:
        ```bash
        git clone --depth 1 https://github.com/acmesh-official/acme.sh.git && cd acme.sh
        ./acme.sh --install -m admin@example.com
        ```

*   **加载环境变量**
    安装完成后，无需注销重新登录，直接执行以下命令即可让 `acme.sh` 命令在当前终端生效：
    ```bash
    source ~/.bashrc
    ```

*   **设定默认 CA (证书颁发机构)**
    `acme.sh` 目前默认的 CA 是 ZeroSSL。通常我们更习惯使用 Let's Encrypt，可通过以下命令切换默认 CA：
    ```bash
    acme.sh --set-default-ca --server letsencrypt
    ```

## 申请与生成证书

建议优先使用 **自动 DNS API 验证**，这种方式无需依赖 Web 服务器（如 Nginx/Apache）的配置，且支持签发泛域名（Wildcard）证书。

### 模式一：自动 DNS API 验证（推荐）

通过调用域名解析服务商的 API，自动添加并删除 TXT 记录完成所有权验证。

*   **阿里云 (Aliyun)**
    获取 RAM 访问控制的 API Key ([阿里云 RAM 控制台](https://ram.console.aliyun.com/users))，然后导入环境变量：
    ```bash
    export Ali_Key="<Your-Ali-Key>"
    export Ali_Secret="<Your-Ali-Secret>"
    ```
    申请证书：
    ```bash
    acme.sh --issue --dns dns_ali -d example.com -d *.example.com
    ```

*   **Cloudflare**
    进入 Cloudflare 仪表盘，为需要申请证书的域名生成一个具有 **编辑 DNS** 权限的 API 令牌 (API Token)。*注意：不要使用全局 API 密钥，以保证安全。*
    ```bash
    export CF_Token="<Your-CF-API-Token>"
    export CF_Zone_ID="<Your-Domain-Zone-ID>"
    ```
    申请证书：
    ```bash
    acme.sh --issue --dns dns_cf -d example.com -d '*.example.com'
    ```

*(💡 扩展提示：如果您后续需要添加腾讯云、AWS 等服务商，只需查阅官方 API 变量名，在此处增加区块即可。)*

### 模式二：DNS 别名模式 (Alias Mode)

**适用场景**：主域名（如 `example.com`）非常重要，不想轻易开放 API 权限；或者主域名的 DNS 服务商不支持 API。此时，可以准备一个专门用于验证的闲置域名（如 `alias.com`，且支持 API），通过 CNAME 将验证请求转交过去。

*   **环境准备**：将验证域名 (`alias.com`) 的 API Token 导入环境变量（以 Cloudflare 为例）：
    ```bash
    export CF_Token="<Your-Alias-Domain-CF-Token>"
    export CF_Zone_ID="<Your-Alias-Domain-Zone-ID>"
    ```

*   **配置 CNAME**：在主域名 (`example.com`) 的 DNS 解析面板中，手动添加 CNAME 记录，指向验证域名：
    ```text
    _acme-challenge.example.com       =>  _acme-challenge.alias.com
    _acme-challenge.www.example.com   =>  _acme-challenge.alias.com
    ```
    *注意：证书颁发后，请勿删除这些 CNAME 记录，后续自动续期时仍需使用。*

*   **申请证书**：使用 `--challenge-alias` 参数指定验证域名：
    ```bash
    acme.sh --issue \
      -d example.com --challenge-alias alias.com --dns dns_cf \
      -d www.example.com \
      -d '*.example.com'
    ```

### 模式三：手动 DNS 验证 (Manual Mode)

**适用场景**：没有任何服务器公网 IP，且 DNS 解析商不支持 API。
**缺点**：**无法自动续期**，每次证书过期前都需要重复手动添加 TXT 记录的步骤。

*   **发起申请**：
    ```bash
    acme.sh --issue -d '*.example.com' --dns \
      --yes-I-know-dns-manual-mode-enough-go-ahead-please
    ```
*   **添加记录**：脚本运行后会暂停，并输出一段 TXT 记录内容。请前往域名控制台手动添加该 TXT 记录。
*   **完成验证**：等待 DNS 记录生效后，执行 `renew` 命令生成证书：
    ```bash
    acme.sh --renew -d '*.example.com' \
      --yes-I-know-dns-manual-mode-enough-go-ahead-please
    ```

## 部署与安装证书

默认情况下，生成的证书文件存储在 `~/.acme.sh/` 隐藏目录下。**绝对不要直接在 Web 服务器中引用该目录下的文件**，因为其内部结构可能会随版本变化。

正确的做法是使用 `--install-cert` 命令，将证书提取（复制）到指定的位置，并触发 Web 服务器重载。

*   **创建证书存放目录**（以 Nginx 为例）：
    ```bash
    sudo mkdir -p /etc/nginx/ssl/example.com
    ```

*   **安装证书并重载服务**：
    ```bash
    acme.sh --install-cert -d example.com \
      --key-file       /etc/nginx/ssl/example.com/key.pem  \
      --fullchain-file /etc/nginx/ssl/example.com/cert.pem \
      --reloadcmd      "systemctl reload nginx"
    ```
    *说明：`--reloadcmd` 后的命令取决于您的系统环境和 Web 服务器。如果是 Apache，可能是 `systemctl reload apache2`。*

## 日常维护

### 证书自动续期
`acme.sh` 会自动创建一个 Cron 定时任务，每天凌晨检查证书状态。当证书有效期不足 30 天（通常 Let's Encrypt 证书总有效期为 90 天，即满 60 天后）时，脚本会自动尝试续期，并执行您在部署时指定的 `reloadcmd` 重启 Web 服务。整个过程无需人工干预。

### 脚本本体更新
为了保持与各 API 接口的兼容性，建议保持 `acme.sh` 处于最新状态。

*   **手动升级**到最新版本：
    ```bash
    acme.sh --upgrade
    ```
*   **开启自动升级**（推荐）：
    ```bash
    acme.sh --upgrade --auto-upgrade
    ```
*   **关闭自动升级**：
    ```bash
    acme.sh --upgrade --auto-upgrade 0
    ```
