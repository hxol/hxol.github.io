# 使用 ExifTool 批量编辑电子书元数据指南

ExifTool 是一款功能极为强大的命令行工具，支持读写各种文件类型的元数据。通过它，我们可以高效地为本地电子书库（如 PDF、EPUB 等）批量清洗、完善书名、作者、出版社等信息。

## 批量编辑元数据

下面是以当前目录为起点，批量修改电子书元数据的核心命令。您可以根据需要直接复制并替换中括号 `[...]` 内的内容。

**针对 PDF 文件**
```bash
exiftool -r -overwrite_original -ext pdf '-Title<${filename;s/\.pdf$//i}' -Author="[作者名]" -Publisher="[出版社名]" -Subject="[丛书系列名]" .
```

**针对 EPUB 文件**
```bash
exiftool -r -overwrite_original -ext epub '-Title<${filename;s/\.epub$//i}' -Author="[作者名]" -Publisher="[出版社名]" -Subject="[丛书系列名]" .
```

> **💡 进阶合并技巧（高可扩展性）**：
> 如果您的文件夹中同时混杂了 PDF 和 EPUB，且作者、出版社均相同，可以使用更通用的正则表达式匹配，一次性处理多种格式：
> ```bash
> exiftool -r -overwrite_original -ext pdf -ext epub '-Title<${filename;s/\.[^.]+$//}' -Author="[作者名]" .
> ```
> *(注：`s/\.[^.]+$//` 的意思是自动删去任意扩展名，无论后缀是 pdf 还是 epub 都能完美提取书名。)*

## 核心参数详解

理解了以下参数的含义后，您可以像搭积木一样自由组合出符合自己需求的命令：

*   **`-r` (Recursive)**
    递归处理。ExifTool 会从指定的起始路径向下搜索，处理该目录及其所有子文件夹中的匹配文件。
*   **`-overwrite_original`**
    直接覆盖原文件。如果不加此参数，ExifTool 默认会在原地生成带有 `_original` 后缀的备份文件。添加此参数可保持书库目录整洁。
*   **`-ext pdf` (Extension)**
    限定文件类型，强烈建议保留。明确告知工具只对特定的后缀格式（如 PDF）进行操作，避免误改目录中的图片、文本或其他不相关的文件。
*   **`-Title<`**
    标签赋值操作符。表示“将后面跟随的动态内容提取并写入到 `Title`（标题）标签中”。如果只是写入固定文本，可以用等号（如 `-Author="xxx"`）；如果需要调用变量，则必须使用 `<`。
*   **`${filename;s/\.pdf$//i}`**
    这是 ExifTool 内置的字符串插值与正则替换语法：
    *   `filename`：代表当前被处理的完整文件名（例如 `西方哲学史.pdf`）。
    *   `s/A/B/i`：Perl 风格的正则表达式替换。意为找到以 `.pdf` 结尾的文本 `\.pdf$`，不区分大小写 `i`，并将其替换为空 `//`。
    *   **效果**：实现自动剔除文件后缀，将干净的纯文件名（如“西方哲学史”）写入元数据标题中。
*   **`.` (英文句号)**
    路径标识。代表操作的起始路径为“当前所在目录”。您也可以将其替换为具体的绝对路径（如 `/Users/Username/Books`）。

## 查看与验证元数据

修改完成后，通过以下命令可以随时核对电子书内部的信息是否已经生效。

**常规查看**
输出文件的主要元数据摘要，适合快速核实。
```bash
exiftool sample.pdf
```

**深度查看所有元数据**
输出文件底层包含的所有元数据，并按照数据所属的群组（Group）进行分类显示，非常适合用于排查疑难杂症。
```bash
exiftool -a -G1 sample.pdf
```
*   `-a`：允许输出所有同名标签（某些文件可能会有重复的标签，加上此参数能避免被隐藏）。
*   `-G1`：按照特定的规范（Family 1）显示每个标签归属的元数据组别（例如是属于 PDF 字典、XMP 还是 Dublin Core）。

## ⚠️ 跨平台环境避坑提示

在终端（Terminal）中运行上述命令时，请注意操作系统的引号规范：

*   **macOS / Linux (Bash/Zsh)**：上面示例中的单引号语法 `'-Title<...'` 可以完美运行，请直接使用。
*   **Windows CMD**：CMD 不支持在单引号内进行复杂的正则运算。如果您使用 Windows，建议在 **PowerShell** 中运行上述命令；如果必须使用传统 CMD，需要将单引号改为双引号，且内部的特定字符可能需要转义。
