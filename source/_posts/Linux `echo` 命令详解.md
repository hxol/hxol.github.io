# Linux `echo` 命令详解

`echo` 是 Linux Shell 中最基础也是最常用的命令，主要用于打印文本、变量值或将内容重定向到文件。尽管简单，但配合转义字符和 ANSI 控制码，它能实现丰富的功能。

## 1. 基本用法

### 基础输出
最简单的用法是直接跟上要输出的文本。
```bash
echo Hello World
# 输出: Hello World
```

### 写入/追加文件
常用于脚本日志记录或配置修改。
```bash
# 覆盖写入 (>)
echo "Starting process..." > log.txt

# 追加写入 (>>)
echo "Process finished." >> log.txt
```

### 变量输出与引用区别（补充内容）
在使用 `echo` 输出变量时，**双引号**与**单引号**的区别至关重要。
*   **双引号 `"`**：弱引用，解析变量。
*   **单引号 `'`**：强引用，原样输出字符。

```bash
name="Linux"
echo "Hello $name"  # 输出: Hello Linux
echo 'Hello $name'  # 输出: Hello $name
```

## 2. 常用选项

`echo` 最核心的两个选项是 `-n` 和 `-e`。

### `-n`：不换行输出
默认情况下，`echo` 会在输出结束后自动添加一个换行符。使用 `-n` 可以抑制这个行为。
```bash
echo -n "Username: "
# 光标将停留在冒号后面，不会换行
```

### `-e`：启用反斜杠转义
默认情况下，`echo` 不解析转义字符（如 `\n`）。使用 `-e` 选项可以让 `echo` 识别这些特殊字符。

```bash
echo -e "Line1\nLine2"
# 输出:
# Line1
# Line2
```

## 3. 转义字符详解 (配合 `-e`)

使用 `echo -e` 时，支持以下常用转义字符：

| 转义字符 | 含义 | 说明 |
| :--- | :--- | :--- |
| **`\\`** | 反斜杠 | 输出 `\` 本身。 |
| **`\n`** | 换行 (Newline) | 光标移至下一行开头。 |
| **`\t`** | 制表符 (Tab) | 相当于按键盘上的 Tab 键，通常用于列对齐。 |
| **`\b`** | 退格 (Backspace) | 删除前一个字符（需注意：如果 `\b` 后没有字符，可能看不出效果）。 |
| **`\c`** | 最后不换行 | 抑制输出结尾的换行符，且 `\c` 之后的内容会被忽略。 |
| **`\r`** | 回车 (Carriage Return) | 光标移至**行首**，不换行。后续输出会覆盖行首原有内容。 |
| **`\f`**, **`\v`** | 换页/垂直制表符 | 换行，但新行的光标位置紧接上一行的行尾（呈阶梯状）。 |
| **`\0NNN`** | 八进制 ASCII | 输出八进制值 NNN 对应的字符（0-3位）。 |
| **`\xHH`** | 十六进制 ASCII | 输出十六进制值 HH 对应的字符（1-2位）。 |

### 典型示例

**1. `\b` 退格键效果**
```bash
echo -e "123\b456"
# 输出: 12456 (3被删除了)
```

**2. `\r` 回车键效果（覆盖）**
```bash
echo -e "abcde\r123"
# 输出: 123de
# 解释: 光标回到行首，输入123覆盖了abc，剩余de保留。
```

**3. `\c` 截断与不换行**
```bash
echo -e "Hello\c World"
# 输出: Hello
# 解释: World 被忽略，且 Hello 后没有换行。
```

## 4. 输出命令执行结果（保留格式）

在使用命令替换（如 `` `cmd` `` 或 `$(cmd)`）时，直接 `echo` 会导致换行符变成空格。

**问题示例：**
```bash
echo $(ifconfig)
# 结果会变成挤在一起的一行乱码
```

**解决方案：**
使用双引号包裹命令替换结果，可保留原命令输出的格式（换行和缩进）。
```bash
echo "$(ifconfig)"
# 结果将完美保留 ifconfig 的多行格式
```

## 5. ANSI 控制码：颜色与特效

通过 `echo -e` 配合 **ANSI 控制码**，可以输出彩色文本、背景色或特殊样式（闪烁、下划线）。

**基本语法：**
```bash
echo -e "\033[<参数>m<文本>\033[0m"
```
*   `\033[` ：控制序列引导符 (CSI)。
*   `m` ：结束符。
*   `\033[0m` ：**重置属性**，防止后续输出也变色。

### 字体颜色 (30-37)

| 代码 | 颜色 | 示例命令 |
| :--- | :--- | :--- |
| 30 | 黑色 | `echo -e "\033[30mBlack\033[0m"` |
| 31 | 红色 | `echo -e "\033[31mRed\033[0m"` |
| 32 | 绿色 | `echo -e "\033[32mGreen\033[0m"` |
| 33 | 黄色 | `echo -e "\033[33mYellow\033[0m"` |
| 34 | 蓝色 | `echo -e "\033[34mBlue\033[0m"` |
| 35 | 紫色 | `echo -e "\033[35mPurple\033[0m"` |
| 36 | 天蓝 | `echo -e "\033[36mCyan\033[0m"` |
| 37 | 白色 | `echo -e "\033[37mWhite\033[0m"` |

### 背景颜色 (40-47)

背景色的代码是字体颜色代码 + 10。

| 代码 | 颜色 | 示例命令 |
| :--- | :--- | :--- |
| 40 | 黑底 | `echo -e "\033[40mBlack BG\033[0m"` |
| 41 | 红底 | `echo -e "\033[41mRed BG\033[0m"` |
| 42 | 绿底 | `echo -e "\033[42mGreen BG\033[0m"` |
| 43 | 黄底 | `echo -e "\033[43mYellow BG\033[0m"` |
| 44 | 蓝底 | `echo -e "\033[44mBlue BG\033[0m"` |
| ... | ... | ... |

### 样式控制与组合

多个参数可以用分号 `;` 隔开。

| 代码 | 含义 |
| :--- | :--- |
| 0 | 重置所有属性 |
| 1 | **高亮/加粗** |
| 4 | <u>下划线</u> |
| 5 | 闪烁 (部分终端不支持) |
| 7 | 反显 (前背景色互换) |
| 8 | 消隐 (隐藏文字) |

**组合示例：**

1.  **黄底红字：**
    ```bash
    echo -e "\033[31;43mWarning!\033[0m"
    ```
2.  **加粗、下划线、绿色：**
    ```bash
    echo -e "\033[1;4;32mSuccess\033[0m"
    ```
3.  **修改命令提示符颜色 (PS1)：**
    (虽然不是 `echo`，但原理相同)
    ```bash
    export PS1="\[\033[32m\]\u@\h:\[\033[34m\]\w\$ \[\033[0m\]"
    ```

## 6. 进阶补充：`echo` vs `printf`

虽然 `echo` 非常常用，但在不同的 Unix/Linux 版本（如 sh, bash, zsh, dash）中，`echo` 的行为（尤其是 `-e` 和 `-n` 的支持）可能不一致。

**最佳实践：**
如果脚本需要极高的跨平台兼容性，或者需要复杂的格式化输出（如对齐、小数点精度），推荐使用 **`printf`**。

```bash
# printf 不需要 -e 即可识别 \n \t
printf "Name: %s\tScore: %.2f\n" "Alice" 98.5
# 输出: Name: Alice   Score: 98.50
```

## 7. 总结速查

1.  **不换行**：`echo -n "text"`
2.  **开启转义**：`echo -e "line1\nline2"`
3.  **保留变量格式**：`echo "$VAR"`
4.  **清空文件**：`echo > file.txt` (或者更简洁的 `> file.txt`)
5.  **输出红色文字**：`echo -e "\033[31mError\033[0m"`
