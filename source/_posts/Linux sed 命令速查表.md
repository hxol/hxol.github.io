# Linux sed 命令速查表
**sed** (Stream Editor) 是流编辑器，以“逐行处理”的方式编辑文本。

- **基本语法**：`sed [选项] '命令' 文件名`
- **核心选项**：
    - `-i`：直接修改文件内容（**危险操作，建议先备份**）
    - `-n`：静默模式，仅显示经过处理的行（常配合 `p` 打印使用）

## 1. 替换 (Substitution)
命令格式：`s/旧内容/新内容/修饰符`

### 基础替换
```bash
# 替换每行第一个匹配的字符串 (输出到屏幕，不改原文件)
sed 's/Jack/Mark/' file.txt

# 全局替换：替换每行中所有匹配的字符串 (g = global)
sed 's/Jack/Mark/g' file.txt

# 直接修改原文件 (-i)
sed -i 's/Jack/Mark/g' file.txt
```

### 指定行替换
```bash
# 仅替换第 2 到第 3 行
sed '2,3s/hello/hey/g' file.txt

# 仅替换包含 "Pony" 的行
sed '/Pony/s/hello/hey/g' file.txt
```

---

## 2. 删除 (Delete)
命令格式：`[地址]d`

### 按行号删除
```bash
# 删除第 2 到第 3 行
sed '2,3d' file.txt

# 删除最后一行 ($ 代表末尾)
sed '$d' file.txt
```

### 按内容删除
```bash
# 删除包含 "Pony" 的行
sed '/Pony/d' file.txt

# 删除所有【不】包含 "Pony" 的行 (! 取反)
sed '/Pony/!d' file.txt
```

### 删除空行
```bash
# 删除纯空行
sed '/^$/d' file.txt

# 删除包含空格、Tab的空行 (\s 代表空白字符，* 代表0或多个)
sed '/^\s*$/d' file.txt
```

---

## 3. 新增 (Append/Insert)
- `a` (append)：在指定行**后**追加
- `i` (insert)：在指定行**前**插入

### 指定行号操作
```bash
# 在第 1 行【前】插入 "welcome"
sed '1i\welcome' file.txt

# 在第 1 行【后】追加 "welcome"
sed '1a\welcome' file.txt
```

### 匹配内容操作
```bash
# 在包含 "Pony" 的行【后】追加 "welcome"
sed '/Pony/a\welcome' file.txt

# 在包含 "Pony" 的行【前】插入 "welcome"
sed '/Pony/i\welcome' file.txt
```

## 4. 正则表达式与转义规则 (重点)
`sed` 默认使用基础正则表达式 (BRE)。符号的**字面意义**与**特殊功能**是否需要转义（`\`）如下表：

### 4.1 常用符号转义表

| 符号 | 用途 | 规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **[ ]** | 字符集合 | 匹配字面 `[]` 需转义；<br>做集合 `[0-9]` **不**转义 | 匹配 `[ ]`: `sed 's/\[.*\]/aaa/g'`<br>匹配数字: `sed 's/[0-9]/x/g'` |
| **( )** | 分组 | 匹配字面 `()` **不**转义；<br>做分组 `\(\)` **需**转义 | 匹配 `( )`: `sed 's/( )/c/g'`<br>分组引用: `sed 's/\(..\)/\1/g'` |
| **{ }** | 次数限定 | 匹配字面 `{}` **不**转义；<br>做限定 `\{\}` **需**转义 | 匹配 `{ }`: `sed 's/{ }/c/g'`<br>匹配3次: `sed 's/[0-9]\{3\}/c/g'` |
| **+** | 1次或多次 | 做特殊字符 **需**转义 `\+` | `sed 's/c\+/aaa/g'` |
| **?** | 0次或1次 | 做特殊字符 **需**转义 `\?` | `sed 's/c\?/aaa/g'` |
| ***** | 0次或多次 | 做特殊字符 **不**需转义 | `sed 's/c*/aaa/g'` |

### 4.2 分组替换 (Backreferences)
当需要保留一部分匹配内容，替换另一部分时，使用 `\(\)` 包裹内容，并在替换部分用 `\1`, `\2` 引用。

**例子：去掉大括号，保留里面的数字**
原内容：`{1234567}`
目标：`1234567`

```bash
# 错误写法：(reg)
# 正确写法：\(reg\)
echo "{1234567}" | sed 's/{\([0-9]*\)}/\1/g'
```
*解释：`\([0-9]*\)` 匹配到的数字被存入第一个分组，`\1` 将其取回。*

## 5. 进阶提示
如果觉得默认的转义规则太繁琐（特别是括号和加号），可以使用 **扩展正则表达式 (-r 或 -E)**，此时 `+`, `?`, `()`, `{}` 默认即为特殊字符，无需转义。

```bash
# 使用 -E 后，+ 和 () 不需要反斜杠转义
sed -E 's/[0-9]+/(number)/g' file.txt
```
