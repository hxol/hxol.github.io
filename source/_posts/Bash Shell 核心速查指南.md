# Bash Shell 核心速查指南

## 1. 变量 (Variables)

### 1.1 变量的定义与引用
Bash 是弱类型语言，默认所有变量值为字符串。

*   **赋值**：`变量名=变量值` (等号两边**不能**有空格)。
*   **引用**：`$var` 或 `${var}` (建议使用 `${}` 避免歧义)。
*   **撤销**：`unset var`。

```bash
# 定义
name="zsy"
# 引用
echo "Hello, ${name}" 
# 拼接防止歧义 (如果不加花括号，系统会寻找 $name_file 变量)
echo "${name}_file.txt" 
```

### 1.2 变量的作用域与类型

| 类型 | 关键字/定义方式 | 说明 |
| :--- | :--- | :--- |
| **本地变量** | `a=1` | 仅在当前 Shell 进程有效，子 Shell 无效。 |
| **环境变量** | `export a=1` | 当前 Shell 及其**子 Shell** 均有效。 |
| **局部变量** | `local a=1` | 仅在函数内部有效，避免污染全局变量。 |
| **只读变量** | `readonly a=1` | 声明后不可修改、不可 unset，退出 Shell 后失效。 |

### 1.3 特殊变量 (位置参数与状态)

| 变量 | 含义 |
| :--- | :--- |
| `$0` | 当前脚本的文件名。 |
| `$n` | 第 n 个参数（`$1` 到 `$9`，超过 9 需用 `${10}`）。 |
| `$#` | 传递给脚本的**参数个数**。 |
| `$?` | 上个命令的**退出状态**（0 为成功，非 0 为失败）。 |
| `$$` | 当前 Shell 的进程 ID (PID)。 |
| `$@` | 所有参数列表。双引号下 `"$@"` 保持每个参数独立（"a" "b" "c"）。**推荐使用**。 |
| `$*` | 所有参数列表。双引号下 `"$*"` 合并为一个字符串（"a b c"）。 |

## 2. 条件测试：`[ ]` 与 `[[ ]]`

### 2.1 核心区别
**推荐尽可能使用 `[[ ]]`**，它是 Bash 的关键字，容错率更高，功能更强。

| 特性 | `[ ... ]` (test 命令) | `[[ ... ]]` (Bash 扩展) |
| :--- | :--- | :--- |
| **逻辑与** | `-a` (例如 `[ $a -eq 1 -a $b -eq 2 ]`) | `&&` (例如 `[[ $a -eq 1 && $b -eq 2 ]]`) |
| **逻辑或** | `-o` | `\|\|` |
| **空变量** | 变量需加双引号 `[ -n "$a" ]` 防止报错 | **不需要**引号 `[[ -n $a ]]` |
| **正则匹配** | 不支持 | 支持 `=~` 运算符 |
| **比较符号** | ASCII比较需转义 `\>` | 直接使用 `>` 或 `<` |

### 2.2 常用测试参数

#### 字符串测试
*   `-z "string"`：长度为 0 则为真（空）。
*   `-n "string"`：长度不为 0 则为真（非空）。
*   `"str1" == "str2"`：字符串相等。
*   `"str1" != "str2"`：字符串不等。

#### 整数比较 (仅适用于整数)
*   `-eq`：等于 (equal)
*   `-ne`：不等于 (not equal)
*   `-gt`：大于 (greater than)
*   `-lt`：小于 (less than)
*   `-ge`：大于等于
*   `-le`：小于等于

#### 文件测试 (补充内容)
*   `-f file`：文件存在且为普通文件。
*   `-d dir`：目录存在。
*   `-e path`：路径存在（文件或目录）。
*   `-r file`：文件可读。
*   `-x file`：文件可执行。

### 2.3 正则匹配示例 (`[[ ]]` 专属)
```bash
file_name="script.sh"
if [[ $file_name =~ \.sh$ ]]; then
    echo "这是一个 Shell 脚本"
fi
```

## 3. 逻辑运算与组合命令

### 3.1 逻辑运算符 (短路运算)
*   `&&` (AND)：**前一个命令成功 ($?=0)**，才执行后一个命令。
*   `||` (OR)：**前一个命令失败 ($?!=0)**，才执行后一个命令。

**常见用法 (类似三元运算)：**
```bash
# 如果 cmd1 成功则执行 cmd2，否则执行 cmd3
cmd1 && cmd2 || cmd3
```

### 3.2 命令组合：`()` 与 `{}`

| 方式 | 语法 | 是否开启子进程 | 变量影响 | 注意事项 |
| :--- | :--- | :--- | :--- | :--- |
| **小括号** | `(cmd1; cmd2)` | **是** (Subshell) | 内部变量修改**不影响**当前 Shell | 退出仅退出子 Shell |
| **大括号** | `{ cmd1; cmd2; }` | **否** | 内部变量修改**影响**当前 Shell | 两端需空格，最后需分号 |

**示例：**
```bash
a=1
(a=2; echo "In subshell: $a")
echo "Main shell: $a"  # 输出 1，变量未改变

{ a=2; echo "In brace: $a"; }
echo "Main shell: $a"  # 输出 2，变量已改变
```

## 4. 算术运算

**推荐使用 `$(( ... ))`**，它是最通用且高效的方法。

| 方法 | 语法示例 | 说明 |
| :--- | :--- | :--- |
| **$(( ))** | `echo $((a+b))` | **推荐**。支持整数，原生 Bash，速度快。 |
| **let** | `let c=a+b` | Shell 内建命令，仅支持整数，无输出(需赋值)。 |
| **expr** | `expr $a + $b` | **不推荐**。古老、慢、符号需转义 (`*` 变 `\*`)。 |
| **bc** | `echo "scale=2; 10/3" \| bc` | **支持浮点数**。Linux 的计算器工具。 |

**浮点运算示例：**
```bash
res=$(echo "scale=3; 10/3" | bc)
echo $res # 输出 3.333
```

## 5. 字符串处理 (Parameter Expansion)

Bash 提供了强大的内置字符串操作，**速度远快于 sed/awk/cut**。

### 5.1 获取长度
```bash
var="hello world"
echo ${#var}      # 输出 11
```

### 5.2 截取字符串 `${var:start:length}`
*   索引从 0 开始。
*   从右往左截取需在冒号后加空格或 0。

```bash
url="www.zsythink.net"
echo ${url:4}      # zsythink.net (从第4位截取到末尾)
echo ${url:4:3}    # zsy (从第4位截取3个字符)
echo ${url:0-3}    # net (截取最后3个字符，注意 0-3 或空格)
```

### 5.3 删除字符串 (掐头去尾)
*   `#` 代表头部（键盘左边），`%` 代表尾部（键盘右边）。
*   一个符号是**最短匹配**，两个符号是**最长匹配**（贪婪匹配）。

| 语法 | 功能 | 助记 |
| :--- | :--- | :--- |
| `${var#*chars}` | 从左删除**最短**匹配 | 掐头 (轻) |
| `${var##*chars}` | 从左删除**最长**匹配 | 掐头 (重) |
| `${var%chars*}` | 从右删除**最短**匹配 | 去尾 (轻) |
| `${var%%chars*}` | 从右删除**最长**匹配 | 去尾 (重) |

**示例：获取文件名和后缀**
```bash
file="/usr/local/src/nginx.tar.gz"
echo ${file##*/}   # nginx.tar.gz (删除最后一个 / 及其左边所有 -> 获取文件名)
echo ${file%/*}    # /usr/local/src (删除最后一个 / 及其右边所有 -> 获取目录)
echo ${file%%.*}   # /usr/local/src/nginx (删除第一个 . 及其右边所有)
```

### 5.4 替换字符串
| 语法 | 功能 |
| :--- | :--- |
| `${var/old/new}` | 替换**第一个**匹配到的字符串 |
| `${var//old/new}` | 替换**所有**匹配到的字符串 |
| `${var/#old/new}` | 仅替换**行首**匹配的字符串 |
| `${var/%old/new}` | 仅替换**行尾**匹配的字符串 |

### 5.5 大小写转换
*   `${var^^}`：全部转大写。
*   `${var,,}`：全部转小写。

### 5.6 默认值处理 (变量为空或未定义时)
| 语法 | 描述 | 变量本身改变吗？ |
| :--- | :--- | :--- |
| `${var:-word}` | 若 var 为空，**返回** word | 否 |
| `${var:=word}` | 若 var 为空，**返回** word 且 **赋值**给 var | **是** |
| `${var:+word}` | 若 var **非空**，返回 word (与 :- 相反) | 否 |
| `${var:?msg}` | 若 var 为空，打印报错信息 msg 并退出脚本 | 否 |

## 6. 补充内容 (原文未涉及的重要知识)

### 6.1 数组 (Arrays)
Bash 支持一维数组。
```bash
# 定义
arr=(A B "C D")
# 引用
echo ${arr[0]}    # 输出第一个元素：A
echo ${arr[@]}    # 输出所有元素
echo ${#arr[@]}   # 数组长度
# 追加
arr+=(E)
```

### 6.2 大括号扩展 (Brace Expansion)
快速生成序列或字符串组合，非常实用。
```bash
echo {1..5}         # 输出 1 2 3 4 5
echo {a,b,c}.txt    # 输出 a.txt b.txt c.txt
mkdir -p /data/{logs,backup,static} # 一次创建多个目录
```

### 6.3 进程替换
将命令的输出模拟为一个临时文件，用于需要文件参数的命令。
```bash
# 比较两个命令输出的差异
diff <(ls /dir1) <(ls /dir2)
```
